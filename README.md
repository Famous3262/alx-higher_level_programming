# ALX Higher-Level Programming

A collection of Python programming exercises from the ALX Software Engineering curriculum.

## Topics covered

The numbered task directories progress through foundational and intermediate Python concepts, including:

- Python syntax and basic scripting
- Conditions, loops, and functions
- Imports and modules
- Lists, tuples, and data structures
- Exceptions and error handling
- Classes and object-oriented programming
- Test-driven development

## Concepts practised

- Writing readable Python programs
- Organizing code into modules
- Working with built-in data structures
- Applying object-oriented programming principles
- Handling errors and writing tests

## Working with the exercises

Each numbered directory represents a separate assignment. Review the task files and instructions in that directory for the required Python version, expected output, and test commands.

## Status

ALX educational coursework / Python learning record. This repository is a collection of exercises rather than a standalone application.
